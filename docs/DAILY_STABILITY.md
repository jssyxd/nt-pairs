## 口径

- 每天 = `--end "<date> 23" --hours 24` 的 24 小时盘口回放（`--end` 是逐日回放的必要条件，否则窗口永远锚定在「现在」）。
- 净 EV 已扣 `b*`（费率 + 半价差 + 滑点 + carry + 腿风险 + 对账），`p_fill` 用的是排队模型（实测标定见 `docs/FILL_CALIBRATION.md`，模型偏保守）。
- 每格会话数字是该会话内的净 EV/事件；`closed` 含周末与非美股时段。

**RTH（美股盘中）是唯一 14/14 全正的会话**，中位净边际 +10.15 bps/事件 ——
是「只在美股盘中交易」这条纪律的直接量化依据：
休市时段虽机会多，但净边际只有 RTH 的几分之一，且有两日为负。

### 逐日净 EV 的时间走势

```
+0.93 +3.45 +8.95 +3.72 +1.24 +3.42 +1.90 +4.69 +5.59 +3.98 +6.83 +4.92 +8.19 +11.78
```

后半段（11-16 起）明显抬升（+4 ~ +12），但**样本只有 14 天，不足以断言这是趋势而非噪声**。
值得警惕的是：若这是费率环境或流动性的一次性改善，回归时净 EV 可能掉到 +1 附近
（11-03 与 11-09 就只有 +0.93 / +1.24）。**按最差日 +0.93 bps/事件做容量规划。**

### 与 p_fill 标定的关系

本报告的 `p_fill` 用的是排队模型值（0.33 ~ 0.61）。实测标定（`docs/FILL_CALIBRATION.md`）
显示模型**偏保守**（实测 0.328 / 0.442 / 0.623 / 0.679 vs 模型 0.205 / 0.276 / 0.389 / 0.432，
TTL = 30/60/120/180s），所以上面的净 EV 是**偏保守的下界**。
若用实测 p_fill 重算，净 EV 会更高 —— 但那需要先解决「重建盘口 + 排队尾假设」这两个上界来源。

### 上实盘前仍需

1. **用真实成交日志复核一次 p_fill**（当前是重建盘口上的模型值 + 实测校准，仍非真实成交）。
2. **扩到更长的窗口**（本轮 14 天；建议至少 30 天，覆盖一次完整的费率周期）。
3. **确认 11-16 之后的抬升不是费率环境的一次性变化**（对比 HL `deployerFeeScale` / growth mode 状态）。
