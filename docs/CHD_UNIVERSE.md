## 口径说明

- base ticker 由场所原生符号归一化得到：HL 取 deployer 前缀后部分，OKX 取 -QUOTE-SWAP 前缀，Binance 去掉 USDT/USDC 等计价后缀与 _YYMMDD 交割后缀，Lighter 去掉 _USDC 后缀。
- 同名不代表同一底层：HL 同一 ticker 存在多个 deployer（xyz / io / flx / cash / km / para / vntl），属于不同发行方与不同定价口径；price_evidence 仅给出同小时价格比，不构成等价证明。
- kind=ticker_like 表示形态像美股代码但不在 Alpha Vantage 上市名单中，需人工复核。
- pre-ipo 名单基于 HL/其他场所的显式命名（OPENAI / ANTHROPIC / OAI / ANTH / SPACEX 等）。
- NON_EQUITY_TICKERS 为手写排除表（加密货币 / 商品 / 外汇 / 指数合约），存在漏判可能。
